Willkommen im Parity Terminal

Live-Kurse und Firmendaten kommen von Finnhub, einem Anbieter für Finanzdaten. Dafür brauchst du einen eigenen, kostenlosen API-Key. Das dauert etwa 2 Minuten.

  1. Kostenloses Konto anlegen. Registriere dich bei Finnhub mit E-Mail und Passwort oder mit Google. Eine Kreditkarte brauchst du nicht. Finnhub-Registrierung öffnen
  2. E-Mail bestätigen. Öffne die Bestätigungsmail von Finnhub und klicke auf den Link darin.
  3. Key kopieren. Melde dich an. Im Dashboard steht ganz oben unter „API Key“ eine lange Zeichenkette. Kopiere sie vollständig. Finnhub-Dashboard öffnen
  4. Key hier einfügen. Füge den Key in das Feld ein und tippe auf „Key prüfen und speichern“.

Dein Key bleibt nur in diesem Browser gespeichert und wird nur an Finnhub gesendet. Der kostenlose Plan erlaubt 60 Anfragen pro Minute. Ist das Limit erreicht, zeigt die Seite einen Hinweis, und du kannst einen anderen Key eingeben.
