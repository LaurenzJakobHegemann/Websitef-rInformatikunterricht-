# KI-Protokoll – Defi-Lücke

Dieses Protokoll dokumentiert, welche Aufgaben KI-Werkzeuge im Projekt übernommen haben und was dabei generiert wurde. Das Projekt wird bei Jugend forscht eingereicht; die KI-Unterstützung muss dort offengelegt werden. Jeder Eintrag nennt, wer das Ergebnis geprüft hat.

| Datum | Aufgabe | Werkzeug/Modell | Was wurde generiert | Geprüft durch |
|---|---|---|---|---|
| 2026-11-15 | M0 Setup | Claude Code (Opus als Hauptagent, Sonnet und Haiku als Unteragenten) | Repo-Gerüst, Konfiguration, CLI-Grundgerüst, Tests, Dokumentationsvorlagen | ausstehend (Team) |
| 2026-11-15 | M1 Daten | Claude Code (Opus als Hauptagent: Planung, Schnittstellen, Datenprüfung, Integration; Sonnet-Unteragenten: Datenabruf, Abdeckung/Optimierer, Validierung/Grafiken, Web-App; Haiku-Unteragenten: Dokumentation) | Abruf- und Aufbereitungscode für AEDs (Overpass), Zensus-Gitter und VG250-EW; Plausibilitätsprüfungen; GeoPackage `data/interim/bernkastel-wittlich.gpkg`; Fetch-Report. Der AED-Snapshot wurde nicht vom Werkzeug abgerufen, sondern vom Menschen manuell über overpass-turbo (GeoJSON-Export, 15.11.2026), weil Overpass aus der Cloud-Umgebung nicht erreichbar war. | ausstehend (Team) |
| 2026-11-15 | M2 Abdeckung | Claude Code (Opus als Hauptagent: Planung, Schnittstellen, Datenprüfung, Integration; Sonnet-Unteragenten: Datenabruf, Abdeckung/Optimierer, Validierung/Grafiken, Web-App; Haiku-Unteragenten: Dokumentation) | Abdeckungsmodell nach SPEC Abschnitt 4; Kennzahlen je Gemeinde, Verbandsgemeinde und Kreis (`metrics_<level>.csv`); Tests zur Abdeckungslogik | ausstehend (Team) |
| 2026-11-15 | M3 Optimierer | Claude Code (Opus als Hauptagent: Planung, Schnittstellen, Datenprüfung, Integration; Sonnet-Unteragenten: Datenabruf, Abdeckung/Optimierer, Validierung/Grafiken, Web-App; Haiku-Unteragenten: Dokumentation) | Greedy-Optimierer für Kandidatenvariante A und B (`optimize_<variant>_<scope>.csv`); Test gegen ein bekanntes Optimum und gegen Brute-Force | ausstehend (Team) |
| 2026-11-15 | M4 Web-App | Claude Code (Opus als Hauptagent: Planung, Schnittstellen, Datenprüfung, Integration; Sonnet-Unteragenten: Datenabruf, Abdeckung/Optimierer, Validierung/Grafiken, Web-App; Haiku-Unteragenten: Dokumentation) | Statische Web-App (Vite, TypeScript, Leaflet) in `web/`; Export der Daten nach `web/public/data/` durch `export-web`; Build nach `web/dist/` | ausstehend (Team) |
| 2026-11-15 | M5 Validierung und Grafiken | Claude Code (Opus als Hauptagent: Planung, Schnittstellen, Datenprüfung, Integration; Sonnet-Unteragenten: Datenabruf, Abdeckung/Optimierer, Validierung/Grafiken, Web-App; Haiku-Unteragenten: Dokumentation) | Validierungscode (Zuordnung, Recall und Precision mit Wilson-Intervallen, optional Chapman-Schätzer); Auswertungsgrafiken (PNG und SVG) und Kennzahlen-CSV je Gemeinde | ausstehend (Team) |
| 2026-11-15 | Integration und Dokumentation | Claude Code (Opus als Hauptagent: Planung, Schnittstellen, Datenprüfung, Integration; Sonnet-Unteragenten: Datenabruf, Abdeckung/Optimierer, Validierung/Grafiken, Web-App; Haiku-Unteragenten: Dokumentation) | Zusammenführung der Module und der CLI; Dokumentation in `docs/methodik.md`, `docs/entscheidungen.md`, `README.md` und diesem Protokoll; Abschnitt „Erste Ergebnisse“ in der Methodik | ausstehend (Team) |
